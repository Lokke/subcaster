# SubCaster Android Resources

## App Icon
Die App verwendet derzeit die Standard-Icons von Capacitor.

Für ein eigenes Icon:
1. Erstelle ein 1024x1024 PNG: `icon.png`
2. Platziere es im `/resources` Ordner
3. Nutze ein Tool wie `capacitor-assets` oder Android Studio

## Splash Screen
Aktuell: Schwarzer Hintergrund mit App-Name

Für einen Custom Splash Screen:
1. Erstelle ein 2732x2732 PNG: `splash.png`
2. Platziere es im `/resources` Ordner
3. Nutze `npx capacitor-assets generate`

## Farben
- Primär: #00ff88 (Grün)
- Hintergrund: #1a1a1a (Dunkel)
- Akzent: #4a4a4a (Grau)
