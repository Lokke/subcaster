🔐 Security Notice

Your Discord bot token will be stored securely on the server and never exposed to the browser.

To get your Discord credentials:

  1. Go to Discord Developer Portal
  2. Create or select your application
  3. Go to "Bot" → Click "Reset Token" to get your bot token
  4. Enable Developer Mode in Discord (Settings → Advanced)
  5. Right-click your channel → "Copy ID" for Channel ID
  6. Right-click your server icon → "Copy Server ID" for Guild ID
